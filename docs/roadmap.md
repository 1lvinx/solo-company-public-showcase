### Phase 10: Multi-Model / Multimodal Agent Layer

**Goal:** Upgrade Solo Company OS from single-assistant workflow into a governed multi-model, multimodal agent system.

**Planned capabilities:**

1. **Model Router** — Route tasks to Claude, GPT, Gemini, DeepSeek/Qwen/MiMo, or local models. Select by cost, reasoning need, privacy level, and task type.

2. **Multimodal Input Layer** — Text, screenshots, images, PDFs/DOCX/XLSX, terminal logs, browser pages, audio/video transcripts.

3. **Agent Roles** — Project Review, Proof Capture, Nuwa Asset Builder, SkillHub Evaluator, Browser Automation, future UI/UX Visual Reviewer, future Client Delivery Agent.

4. **Tool Integration** — Peekaboo (app/window capture), shot-scraper (web screenshots), MarkItDown (document conversion), Browser-use / Playwright MCP (browser automation), Superpowers (engineering discipline).

5. **Governance** — Every agent action goes through Task Ticket. L3/L4 risks require explicit approval. No unrestricted browser/desktop automation. No model key exposure. Cost tracking required. Proof capture required for completion claims.

**Recommended sub-phases:**
- Phase 10-A: Model Router design
- Phase 10-B: Multimodal input adapter design
- Phase 10-C: Agent permission model
- Phase 10-D: Cost and token governance
- Phase 10-E: First real multi-model dry run

**Do not implement yet:**
- No API keys now
- No global Claude/Agent config modification
- No autonomous browser/desktop control
- No production Agent Supervisor yet
- No client data connection

> Multi-model and multimodal agents are planned as a future expansion after the public showcase is launched and internal agents are tested.
