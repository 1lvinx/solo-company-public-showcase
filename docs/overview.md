# Overview

> What Solo Company OS is and how it works.

## What Is Solo Company OS?

Solo Company OS is a structured operating system designed for solo developers and one-person companies who build with AI. It provides the discipline, workflow, and proof capture that turns scattered AI-assisted work into a reliable, repeatable business operation.

## Who Is It For?

- Solo developers using AI coding tools (Claude Code, Cursor, Copilot)
- One-person companies building AI-powered products
- Freelancers who need to demonstrate work quality to clients
- Anyone who wants structure in their AI-assisted development workflow

## Core Philosophy

**Discipline over speed.** AI tools are fast but reckless. Solo Company OS enforces quality gates that prevent AI from rushing to code without understanding requirements, skipping tests, or claiming completion without evidence.

**Proof over claims.** Every piece of work is captured, validated, and tracked. You can demonstrate your work quality, not just claim it.

**Reuse over repetition.** Experience is captured into reusable skills, templates, and workflows. Future work builds on proven patterns, not starting from scratch.

## How It Works

### Operating Gates

Five enforced gates ensure quality at every step:

1. **Task Ticket** — No coding without clear requirements
2. **Risk Review** — Every risk scored and tracked (L1-L4)
3. **Code Review** — Mandatory review before completion
4. **Daily Report** — Daily activity and progress tracking
5. **Push/Tag Approval** — No unreviewed changes to production

### Daily Operating Loop

```
Morning: Review cockpit dashboard
  ↓
Create task tickets for today's work
  ↓
Work with AI (gates enforced)
  ↓
Capture proof of completed work
  ↓
End of day: Generate daily report
  ↓
Review risks, update registers
```

### Proof Capture

Three-tool capture stack documents your work:

- **Peekaboo** — macOS app/window detection and screenshots
- **shot-scraper** — Web page and HTML capture
- **screencapture** — Full screen fallback

Every screenshot validated visually, tracked in manifest, indexed by category.

### SkillHub

Reusable skills and prompt library:

- Skills evaluated before installation
- Internal custom skills for asset creation
- Controlled intake process

### Internal Agents

Automated agents maintain operating discipline:

- Project Review Agent — daily health checks
- Proof Capture Agent — automated screenshot workflows
- Nuwa Asset Builder — experience to reusable assets

## What Makes It Different

| Feature | Typical AI Coding | Solo Company OS |
|---------|-------------------|-----------------|
| Discipline | None — AI does what it wants | 5 enforced gates |
| Proof | None — trust the AI | Visual proof capture |
| Reuse | None — start over each time | SkillHub + Nuwa |
| Accountability | None — no tracking | Daily reports + risk register |
| Cost control | None — token waste | Token cost policy |
