## Operating Gates

**What:** Five enforced gates for quality control.

| Gate | Purpose |
|------|---------|
| Task Ticket | No coding without requirements |
| Risk Review | Every risk scored and tracked |
| Code Review | Mandatory review before completion |
| Daily Report | Daily activity tracking |
| Push/Tag Approval | No unreviewed production changes |

**Result:** AI-assisted work with human-level discipline.
