## Installation Policy

1. **No batch install** — one skill at a time
2. **Verify source first** — all 10 evaluation checkpoints must PASS
3. **Snapshot before install** — create backup
4. **No global config modification** — without approval
5. **Record all results** — install and rollback documented

## Nuwa Creation Skill

**Purpose:** Turn scattered work into reusable company assets.

**Workflow:**
1. 识别 (Identify) — Find reusable elements
2. 提取 (Extract) — Remove project-specific details
3. 结构化 (Structure) — Add metadata and workflow
4. 验证 (Validate) — Check reusability
5. 归档 (Register) — Add to Solo Company OS

**Outputs:** Skills, SOPs, templates, checklists, service packages, risk rules.
