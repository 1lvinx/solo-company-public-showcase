# Solo Company OS

> Public-safe preview package for a one-person AI-powered company operating system.

## What Is This?

Solo Company OS is a structured operating system designed for solo developers and one-person companies who build with AI. It provides the discipline, workflow, and proof capture that turns scattered AI-assisted work into a reliable, repeatable business operation.

## Why Was It Built?

AI coding tools are powerful but chaotic. Without structure, you waste tokens, lose context, skip tests, and can't prove your work. Solo Company OS solves this by providing:

- **Operating gates** that enforce discipline (task tickets, risk reviews, code reviews, daily reports)
- **Proof capture** that documents your work visually
- **SkillHub** that turns experience into reusable assets
- **Internal agents** that automate routine checks

## Core Modules

| Module | Purpose |
|--------|---------|
| Cockpit | Daily operating dashboard |
| Workflows | Task, risk, and code review processes |
| Company OS | Business-level operating modules |
| Business Pack | Service packages, pricing, client intake |
| Proof Capture | Screenshot capture, validation, tracking |
| SkillHub | Reusable skills and prompt library |
| Internal Agents | Automated health checks and asset creation |

## What Is Intentionally Private

This preview package stays public-safe. The following remain intentionally private:

- Internal IP addresses and server configurations
- SSH credentials and access details
- API keys and tokens
- Client data and delivery notes
- Private screenshots containing sensitive information
- Live service URLs (Plane, Homarr)

The public showcase demonstrates the system architecture, capabilities, and approach. Live infrastructure and private operational details stay out of scope.
