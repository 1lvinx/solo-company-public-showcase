# Solo Company OS

## The Operating System for One-Person AI Companies

---

## The Problem

AI coding tools are powerful but chaotic. Solo developers using Claude Code, Cursor, and Copilot face:

- **Token waste** — loading irrelevant context, wrong model choices, repeated explanations
- **No discipline** — AI rushes to code without understanding, skips tests, claims completion without evidence
- **No proof** — can't demonstrate work quality to clients or collaborators
- **No structure** — scattered workflows, no operating rhythm, no accountability

## The Solution

Solo Company OS provides the operating system that turns AI-assisted work into reliable business operations.

### Operating Gates

Five enforced gates ensure quality at every step:

1. **Task Ticket** — No coding without clear requirements
2. **Risk Review** — Every risk scored and tracked
3. **Code Review** — Mandatory review before completion
4. **Daily Report** — Daily activity and progress tracking
5. **Push/Tag Approval** — No unreviewed changes to production

### Proof Capture Engine

Three-tool capture stack that documents your work:

- **Peekaboo** — macOS app/window detection and screenshots
- **shot-scraper** — Web page and HTML capture
- **screencapture** — Full screen fallback

Every screenshot validated, tracked, and indexed.

### SkillHub

Reusable skills and prompt library that turns experience into assets:

- 12 skill candidates registered
- Internal custom skills for asset creation
- Controlled evaluation and installation process

### Internal Agents

Automated agents that maintain operating discipline:

- Project Review Agent — daily health checks
- Proof Capture Agent — automated screenshot workflows
- Nuwa Asset Builder — experience to reusable asset conversion
